# NGD Concept — Protótipo de Gestão de Vendas & Rentabilidade

Protótipo interativo Mobile-First de alta fidelidade desenvolvido para a loja de moda masculina e streetwear **NGD CONCEPT** (@ngdconceptbh - Belo Horizonte / MG).

---

## 🌟 Destaques do Projeto

- **Dois Temas Visuais Exclusivos**:
  - 🖤 **Preto & Dourado** (`black-gold`): Estilo luxury streetwear, fundo escuro com detalhes em dourado acetinado.
  - 🤍 **Branco & Dourado** (`white-gold`): Minimalismo sofisticado boutique com alto contraste e clareza.
- **Gaveta Lateral de Gestão (Drawer)**:
  - 8 Módulos completos: **Clientes** (Top Clientes, Dados, Histórico), **CRM** (Plano VIP Fidelidade), **Metas**, **News**, **Precificação**, **Academy**, **+ Produtos** (Gestão ágil de estoque com grade) e **Ajuda**.
- **Dashboard Financeiro & Comercial**:
  - Filtro por período dinâmico (**Hoje**, **7 Dias**, **30 Dias**).
  - Métricas chave: Faturamento Bruto, Lucro Bruto, Margem de Lucro (%) e Margem Líquida.
  - Cartões de detalhamento: Ticket Médio, Total de Vendas, CMV (Custo da Mercadoria Vendida) e Despesas Fixas rateadas.
  - Demonstrativo de Resultados (DRE) em barras progressivas organizadas.
- **Barra de Navegação Inferior (Bottom Bar)**:
  - 📊 Dashboard
  - 🧾 Vendas (Histórico de vendas por data e forma de pagamento)
  - ➕ Botão Central de Nova Venda (com seleção de peças, cliente, quantidade, preço e forma de pagamento: Pix, Cartão Crédito/Débito, Dinheiro)
  - 💵 Fluxo de Caixa (Entradas, saídas e saldo projetado)
  - ⚙️ Ajustes

## 🚀 Como subir para o GitHub e ativar o GitHub Pages

### 1. Criar o repositório no seu GitHub
Crie um novo repositório vazio no seu GitHub (ex.: `ngd-concept` ou `gestao-vendas-app`).

### 2. Vincular o repositório e enviar o código
No terminal, dentro desta pasta:
```bash
git remote add origin https://github.com/morluto/ngd-concept.git
git push -u origin main
```

### 3. Ativar o link público no GitHub Pages
1. Acesse seu repositório no GitHub.
2. Vá em **Settings** > **Pages** (no menu lateral esquerdo).
3. Em **Build and deployment** > **Source**, selecione `Deploy from a branch`.
4. Escolha a branch `main` e a pasta `/(root)`.
5. Clique em **Save**.
6. Em cerca de 1 minuto, seu link estará online no formato:
   `https://morluto.github.io/ngd-concept/`
